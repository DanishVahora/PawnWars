## 🚀 Features That Will Make You Say "En Passant!"

### Multiplayer Mode 🔥
- **Real-time moves** faster than a knight on energy drinks ♘
- **Chat** with your opponent (trash talking optional but encouraged) 💬
- **Room system** so secure even the Black Queen can't crash your game ♛

### AI Mode 🤖
- **Stockfish integration** (Difficulty levels: "Wait I can win" to "I need adult supervision") 🧠
- **Eval bar** that brutally shows how bad you're doing 📊
- **Undo button** for when you pretend you meant to make that move ↩️

### Special Sauce 🌶️
- **Click OR Drag** - For those who can't decide how to move pieces
- **Move history** to relive your glory moments (or tragic mistakes) 📜
- **Responsive design** that works on everything from 4K monitors to smart fridges 🖥️❄️

## 🛠️ Installation (For When You're Board... Get it?)

1. **Clone the repo** - `git clone https://github.com/yourusername/pawn-wars.git`
2. **Navigate to the dungeon** - `cd pawn-wars`
3. **Install dependencies** - `npm install` (both in root and client folders)

**Client Side:**
```bash
cd client
npm run dev # (the official chess referee)
```

**Server Side:**
```bash
npm start # Warning: May cause chess addiction
```
